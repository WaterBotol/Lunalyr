## ICU 72.1: traditional-to-simplified Chinese table

- **What:** the table of 2,852 traditional Chinese characters and their simplified forms that lyric lookup uses to
  compare names in either script (`src/Lunalyr.Core/Lyrics/Ranking/ChineseScripts.cs`). It was generated by applying
  ICU's `Hant-Hans` transform to each character of the CJK blocks and keeping the characters it changes, one
  character to one; the 苎/苧 pair, which ICU swaps both ways, is listed once. The data is modified in form only
  (written as character pairs); no ICU code is included.
- **Source:** ICU 72.1 as installed with Windows (`icu.dll`), whose transform rules come from ICU's
  `icu4c/source/data/translit/Hant_Hans.txt` (<https://github.com/unicode-org/icu>).

## IPAdic (mecab-ipadic) 2.7.0-20070801

- **What:** the Japanese dictionary used for kanji readings and Japanese word breaks: its word lists, connection
  costs and character categories, converted by Lunalyr's own tool (`tools/JapaneseDictionaryBuilder`) into Lunalyr's
  dictionary format and compressed (`src/Lunalyr.Platform.Windows/Readings/Data/ipadic.lunadic.br`). The data is
  modified in form only: re-encoded from EUC-JP to UTF-16 and laid out for lookup, keeping each word's surface,
  connection ids, cost and reading (the base-form and pronunciation columns are left out, and parts of speech are
  kept once per connection id). The analyser that reads it is Lunalyr's own code; no MeCab code is included.
- **Source:** <https://github.com/taku910/mecab/tree/2fd29256c6d5e1b10211cac838069ee9ede8c77a/mecab-ipadic> (the
  MeCab project's repository, commit "update to mecab-ipadic-20070801").
