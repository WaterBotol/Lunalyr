# Lunalyr documentation

Installing and using Lunalyr is covered in the main [README](../README.md). The contributor workflow is in [CONTRIBUTING.md](../CONTRIBUTING.md). This folder holds the longer reference material.

| Document | What it covers |
| --- | --- |
| [Architecture](ARCHITECTURE.md) | The source tree, how data flows from the Music app to the desktop, the visualiser pipeline, settings and storage, and building and testing. |
| [Releasing](RELEASING.md) | Versioning, the update feed, signing keys, and publishing preview and stable releases. For maintainers. |
| [Validation records](VALIDATION.md) | What was actually tested for each release, and what was not. |
| [External formats and system APIs](INTEROPERABILITY.md) | Lyric export formats, the Apple frameworks used for audio and rendering, and the update infrastructure. |
| [Upstream Verso](upstream/README.md) | Verso's original README, the [upstream pin](upstream/UPSTREAM.json) and the [early modification record](upstream/MODIFICATIONS.md). |

[`images/`](images/) holds the README screenshots and the repository's social preview image (`social-preview.jpg`, 1280×640), which is uploaded by hand in the repository settings.

Version history is in [CHANGELOG.md](../CHANGELOG.md), and licences for bundled third-party code are in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
